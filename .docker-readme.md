# This project can run in Docker with a single command:
# docker compose up --build
#
# Then open:
# - Client: http://localhost:5173
# - Admin: http://localhost:8089
# - Backend API: http://localhost:8080
# - MinIO Console: http://localhost:9001
#
# If you want to change backend credentials, edit docker-compose.yml or create a .env file.
